# Blazor Server DataGrid - GridEdit using EditForm

A practical sample demonstrating complete CRUD operations using Blazor components. This project showcases how to build a [Blazor DataGrid](https://www.syncfusion.com/blazor-components/blazor-datagrid) with inline editing capabilities, leveraging the power of Blazor's `EditForm` component paired with Syncfusion's rich component library.

## Overview

This sample application provides a real-world example of building data-driven web applications with Blazor Server. It features a responsive order management interface where users can view, add, edit, and delete records through an intuitive datagrid and form-based UI.

## Key Features

- **DataGrid Display**: Browse orders with sortable columns and pagination
- **Add Records**: Create new orders with dedicated form interface
- **Edit Records**: Double-click grid rows to edit existing orders  
- **Delete Records**: Remove records with confirmation dialog
- **Form Validation**: Built-in validation using Blazor's `EditForm` and data annotations
- **Rich Components**: Leverages Syncfusion components (TextBox, DatePicker, NumericTextBox, DropDownList)

## Getting Started

### Prerequisites

- [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later
- [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or later
- [Visual Studio Code](https://code.visualstudio.com/)

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/Blazor-Server-Grid-Edit-Form.git
cd Blazor-Server-Grid-Edit-Form
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
